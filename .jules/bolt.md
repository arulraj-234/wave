## 2024-05-24 - Optimize massive IN clauses during metadata enrichment
**Learning:** When fetching metadata (like artists) for arrays of entities (like songs) using SQL `IN` clauses, unpaginated arrays can cause bottleneck issues due to massive queries. It is crucial to skip entities that already have the metadata populated. I learned that just filtering `song_ids` before the query isn't enough; you must also explicitly skip the overwrite logic when attaching the metadata back to the entities.
**Action:** When enriching data arrays in Python, check for explicit key presence (e.g., `'artists' in s`) to minimize `IN` clause sizes. Also, ensure the attachment loop contains a `continue` condition to prevent overwriting existing valid metadata with default empty states from the batch fetch results.
