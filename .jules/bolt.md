## 2026-05-24 - Cached get_artist_stats endpoint\n**Learning:** The /artist/<id> endpoint was executing 16+ complex SQL queries per request, creating a massive DB bottleneck under load. The 'engine.cache' module is a safe and effective way to mitigate this by caching the final payload.\n**Action:** Always check analytics and dashboard endpoints for caching opportunities, especially when they aggregate data using multiple queries.
