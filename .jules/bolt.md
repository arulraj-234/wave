## 2024-05-26 - PlayerContext Re-renders
**Learning:** Storing rapidly changing `<audio>` state like playback `progress` (updated via the `timeupdate` event multiple times per second) inside a React Context (`PlayerContext`) causes massive global re-renders. Every component consuming the context (e.g., `SongCard`, `Dashboard`, `BottomPlayer`) re-renders on every tick, destroying performance and negating optimizations like `React.memo`.
**Action:** Expose the `audioRef` via Context instead of the derived state. Components that need high-frequency updates (like the progress bar in `BottomPlayer`) should consume `audioRef` and manage their own local state by attaching direct event listeners to the audio element. This localizes the re-renders to only the components that visually change.
